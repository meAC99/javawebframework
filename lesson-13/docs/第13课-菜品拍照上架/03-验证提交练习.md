# 第13课 · 验证、提交与练习

## 一、requests.http 追加：multipart 请求怎么写

REST Client 发 multipart 有专用语法（IDEA 与 VS Code 插件通用）。在文件末尾追加：

```
### 13.1 上架回锅肉照片（multipart：boundary 分界线 + < 引用本地文件）
POST http://localhost:8080/menu/1/image
Content-Type: multipart/form-data; boundary=WebAppBoundary

--WebAppBoundary
Content-Disposition: form-data; name="file"; filename="dish.png"
Content-Type: image/png

< ./dish.png
--WebAppBoundary--

### 13.2 上传非图片文件（预期 code=40403）
POST http://localhost:8080/menu/1/image
Content-Type: multipart/form-data; boundary=WebAppBoundary

--WebAppBoundary
Content-Disposition: form-data; name="file"; filename="fake.txt"
Content-Type: text/plain

< ./fake.txt
--WebAppBoundary--
```

语法拆解（对照课程导入里讲的 multipart 结构）：

- `boundary=WebAppBoundary`：分界线名字自己起，请求头和正文要一致
- 每个部件有小头部：`name="file"` 就是 `@RequestParam("file")` 等的名字；`filename` 是原始文件名
- **`< ./dish.png`**：从 .http 文件所在目录读取本地文件作为部件内容——课前准备的图片这时上场

## 二、验证清单（全过才算下课）

**1. 发送 13.1 上传照片**

预期：

```json
{"code":200,"data":"/files/e31a8925-06c7-46f2-...png","msg":"操作成功"}
```

`data` 里那串 UUID 文件名**抄下来**——下一课和本课后面都要用。然后到项目根目录的 `upload/` 里看：同名文件真实躺在磁盘上。

**2. 发送 13.2 上传 txt**

预期：`{"code":40403,"data":null,"msg":"文件为空或格式不支持（仅限图片）"}`——白名单拦截。`upload/` 里也**不会**多出任何文件。

**3. 空文件测试**

把 `dish.png` 复制一份命名为 `empty.png`，清空内容，再仿照 13.1 发一次（filename 改 empty.png）→ 同样 40403。

**4. 钩子验证：照片存了，但看不了**

```
### 【钩子】试着访问刚上传的照片（预期：此刻还是 40404！）
GET http://localhost:8080/files/<把13.1返回的uuid填这里>
```

预期：`{"code":40404,...,"msg":"访问路径不存在"}`。文件明明在磁盘上，路径也返回给前端了，为什么访问不到？——因为 Spring Boot 的静态资源默认只认 `static/` 那几个目录（第 1 课的约定），`upload/` 不在名单里。**给 /files/** 指路的映射，就是下一课的开场。别修，留着。

**5. 回归**：2.1 查菜单正常（imageUrl 此刻是 null，前端显示不变——第 14 课才显示图）；2.2 下单正常。
