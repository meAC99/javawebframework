# 第17课 · 动手做：Spring AI 接入与小智聊天

共 6 步。

## Step 1：pom 加 Spring AI（10 分钟）

`pom.xml` 两处修改：

**① `<properties>` 加版本号**：

```xml
	<properties>
		<java.version>17</java.version>
		<spring-ai.version>2.0.1</spring-ai.version>
	</properties>
```

**② `<dependencies>` 加 starter**（放在 spring-security-crypto 之后）：

```xml
		<!-- 第17课：Spring AI——OpenAI 兼容客户端（智谱 GLM/DeepSeek 等皆可，换模型只改配置） -->
		<dependency>
			<groupId>org.springframework.ai</groupId>
			<artifactId>spring-ai-starter-model-openai</artifactId>
		</dependency>
```

**③ `</dependencies>` 之后、`<build>` 之前加 BOM**（版本统一管理，和 parent 管依赖版本同一思路）：

```xml
	<!-- 第17课：Spring AI 版本由 BOM 统一管理 -->
	<dependencyManagement>
		<dependencies>
			<dependency>
				<groupId>org.springframework.ai</groupId>
				<artifactId>spring-ai-bom</artifactId>
				<version>${spring-ai.version}</version>
				<type>pom</type>
				<scope>import</scope>
			</dependency>
		</dependencies>
	</dependencyManagement>
```

版本说明（重要）：**Spring AI 2.0.x 是面向 Spring Boot 4 的版本线**——网上大量教程基于 1.x（配 Boot 3），API 有差异，别混抄。

## Step 2：application.yml 加 AI 配置（15 分钟）

在 `spring:` 段（`servlet:` 之后）追加：

```yaml
  # 第17课：AI 服务员——OpenAI 兼容端点（默认智谱 GLM，DeepSeek/DashScope 皆可换）。
  # Key 用环境变量 NANPO_AI_KEY 注入（与第15课 JWT 密钥同一套思路）：
  #   export NANPO_AI_KEY=你的key && ./mvnw spring-boot:run
  # 不配置也能启动——AI 接口返回"AI 服务暂时不可用"（50002），其余功能不受影响。
  # 智谱注意：兼容端点在 /api/paas/v4，而 Spring AI 默认拼 /v1/chat/completions，
  # 所以 base-url 写到 v4、completions-path 改成 /chat/completions
  ai:
    openai:
      api-key: ${NANPO_AI_KEY:demo-key-not-set}
      base-url: ${NANPO_AI_BASE:https://open.bigmodel.cn/api/paas/v4}
      chat:
        completions-path: ${NANPO_AI_CHAT_PATH:/chat/completions}
        options:
          model: ${NANPO_AI_MODEL:glm-4-flash}
          temperature: 0.7
```

逐行看懂：

- **api-key**：`${NANPO_AI_KEY:demo-key-not-set}`——先找环境变量，没有就用后面的占位值。**没 Key 也绝不阻断启动**，这是本课"优雅降级"设计的第一半。
- **base-url + completions-path**：这是本课的**智谱大坑**。Spring AI 默认请求 `{base-url}/v1/chat/completions`，而智谱的兼容端点是 `https://open.bigmodel.cn/api/paas/v4/chat/completions`——所以 base-url 写到 `/v4`，再把 completions-path 改成 `/chat/completions`，拼出来刚好正确。换 DeepSeek 时改 `NANPO_AI_BASE=https://api.deepseek.com` 和对应 path 即可。
- **model / temperature**：模型名（glm-4-flash 是智谱的免费档）；temperature 0.7——越高越"放飞"，越低越"规矩"。

## Step 3：AiService——小智的大脑（20 分钟）

新建 `service/AiService.java`：

```java
package com.cdutetc.nanpo.service;

import org.springframework.ai.chat.client.ChatClient;
import org.springframework.stereotype.Service;

import com.cdutetc.nanpo.common.BusinessException;
import com.cdutetc.nanpo.common.ErrorCodeEnum;

/**
 * AI 服务员"小智"（第17课）：基于 Spring AI 的聊天服务。
 * ChatClient.Builder 由 spring-ai-starter-model-openai 自动装配——
 * 端点/模型/Key 全部来自 yml 的 spring.ai.openai.* 配置，换模型只改配置。
 */
@Service
public class AiService {

    private final ChatClient chatClient;

    public AiService(ChatClient.Builder chatClientBuilder) {
        // 系统提示词：给 AI 定"人设"——南坡小炒的服务员小智
        // （Spring AI 2.0 的 Builder 方法叫 defaultSystem——设置默认系统提示词）
        this.chatClient = chatClientBuilder
                .defaultSystem("你是成都理工大学工程技术学院南坡小炒饭馆的AI服务员，名叫小智。" +
                        "你熟悉川菜家常菜，回答热情简短（两三句话），最后可以自然地引导顾客点单。" +
                        "如果顾客的问题与饭馆无关，礼貌地把话题拉回点餐。")
                .build();
    }

    /** 聊天：一问一答（单轮；多轮记忆留作拓展） */
    public String chat(String message) {
        try {
            return chatClient.prompt()
                    .user(message)      // 顾客的话
                    .call()             // 发起调用
                    .content();         // 取回复文本
        } catch (Exception e) {
            // 无 Key/网络不通/额度用尽——统一转成友好提示，不让异常栈吓到顾客
            throw new BusinessException(ErrorCodeEnum.AI_SERVICE_ERROR);
        }
    }
}
```

四个看点：

- **`ChatClient.Builder` 是注入来的**——starter 自动装配（第 7 课"自动配置"的又一次现身）：你只配了 yml，端点/模型它全组装好了。
- **`defaultSystem`**：人设写在这里。注意版本坑：Spring AI 2.0 的 Builder 方法叫 `defaultSystem`，老教程的 `.system()` 是 1.x 写法，编译会报"找不到符号"（本课程开发时真实踩过）。
- **调用链四连**：`prompt().user(话).call().content()`——发起、传话、等待、取文本。
- **catch 转 50002**：无 Key 时底层会抛鉴权异常——我们不把它原样抛出去（顾客看不懂），转成 `AI_SERVICE_ERROR` 友好提示。**AI 是增强，不是命根子：小智请假，店照开**。

错误码字典加词（`ErrorCodeEnum` 的 5xxxx 区）：

```java
    /* 5xxxx 系统类错误 */
    SYSTEM_ERROR(50001, "服务器内部错误"),
    AI_SERVICE_ERROR(50002, "AI 服务暂时不可用，请稍后再试");
```

## Step 4：ChatRequest + AiController（10 分钟）

`dto/ChatRequest.java`：

```java
package com.cdutetc.nanpo.dto;

import lombok.Data;

/** AI 对话请求（第17课）：{ "message": "有什么不辣的菜？" } */
@Data
public class ChatRequest {

    private String message;
}
```

`controller/AiController.java`——第四个窗口开张：

```java
package com.cdutetc.nanpo.controller;

import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RestController;

import com.cdutetc.nanpo.common.Result;
import com.cdutetc.nanpo.dto.ChatRequest;
import com.cdutetc.nanpo.service.AiService;

/**
 * AI 服务员窗口（第17课）：和小智聊天。
 * 公开接口——聊天自由（第16课的规矩：逛店聊天随便，动真格下单才要亮卡）。
 */
@RestController
public class AiController {

    @Autowired
    private AiService aiService;

    // 和 AI 服务员聊天
    @PostMapping("/ai/chat")
    public Result<String> chat(@RequestBody ChatRequest req) {
        return Result.success(aiService.chat(req.getMessage()));
    }
}
```

## Step 5：前端聊天区（15 分钟）

`index.html` 三处：

**① 账本区（`<pre id="orders">`）之后加**：

```html
<!-- AI 区（第17课）：AI 服务员小智 -->
<div class="ai">
    <h3>🤖 AI 服务员·小智</h3>
    <div>
        <input id="aiInput" placeholder="问小智：有什么不辣的菜？">
        <button class="ai-btn" onclick="askAi()">问小智</button>
    </div>
    <div id="aiReply" class="ai-reply">小智待命中…（未配置 NANPO_AI_KEY 时会说"AI 服务暂时不可用"）</div>
</div>
```

**② CSS 追加**：

```css
        .ai { margin-top: 20px; padding: 12px; background: #fff; border: 1px solid #e8e8e8; border-radius: 8px; }
        .ai h3 { margin: 0 0 8px; font-size: 15px; }
        .ai input { flex: 1; min-width: 200px; padding: 6px; }
        .ai > div:first-of-type { display: flex; gap: 6px; }
        .ai-btn { width: auto; margin-top: 0; padding: 6px 12px; font-size: 14px; background: #2980b9; }
        .ai-reply { margin-top: 8px; padding: 10px; background: #f4f9ff; border-radius: 6px; font-size: 14px; min-height: 20px; white-space: pre-wrap; }
```

**③ script 末尾加函数**：

```js
    // ===== AI 服务员（第17课）：和小智聊天 =====
    function askAi() {
        const msg = aiInput.value.trim();
        if (!msg) { alert('想问点什么？'); return; }
        aiReply.textContent = '小智思考中…';
        fetch('/ai/chat', {
            method: 'POST',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify({ message: msg })
        })
        .then(r => r.json())
        .then(result => {
            aiReply.textContent = result.code === 200 ? result.data : '❌ ' + result.msg;
        });
    }
```

前端第六次联动完成。

## Step 6：重启验证

```bash
./mvnw spring-boot:run
```

首次构建会下载 Spring AI 一堆依赖，耐心。启动后**先不配 Key 直接测**（降级路径），细节见下一文件。

> **常见报错**
>
> | 现象 | 原因 | 解法 |
> |---|---|---|
> | `.system(...)` 找不到符号 | 抄了 1.x 教程 | 用 `defaultSystem` |
> | 聊天报 50001 而非 50002 | catch 没包住/没加错误码 | 对照 Step 3 |
> | 配了 Key 仍 401 | Key 错 / base-url 与 path 拼错 | 对照 Step 2 的智谱路径说明 |
