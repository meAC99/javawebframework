## 为什么是 H2？什么是 JPA？

**H2** 是一个用 Java 写的小型数据库，可以完全跑在内存里——不用安装任何软件、启动项目它就跟着启动，非常适合课堂和开发期。它的"重启即清零"在本课程反而是优点：每次上课都是干净的库，不怕演示数据越积越乱（真实项目的持久化，第 19 课换 MySQL 容器兑现）。

**JPA**（Java Persistence API）是 Java 官方的"对象-关系映射"标准，**Hibernate** 是它最主流的实现。一句话理解 ORM：**对象和表之间的翻译官**——你操作 Java 对象（menu.setPrice(...)），它负责翻译成 SQL（update t_menu set price=...）发 给数据库。第 8 课你会第一次体会"不写 SQL 也能操作数据库"。

## 一个先想清楚的问题：为什么"配置了却不生效"是最阴险的坑？

这节课你会故意踩一个坑：把 H2 控制台的开关（`spring.h2.console.enabled=true`）配置好，重启，访问 `/h2-console`——**404，配置完全不生效**。

配置明明写了、语法明明没错，为什么？因为 Spring Boot 4 把"自动配置"拆成了一堆小模块：**配置只是"愿望"，对应的自动配置模块不在类路径上，愿望就没人实现**。这个坑的完整机理课上展开，先带着问题往下走——它会让你对"约定优于配置"的理解从"背口诀"变成"懂原理"。
