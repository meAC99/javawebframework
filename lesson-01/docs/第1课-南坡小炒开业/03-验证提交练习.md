# 第1课 · 验证、提交与练习

## 一、创建你的"点餐工具"——requests.http（本课起贯穿全课程）

从这节课起，验证接口不再靠手敲浏览器地址，而是用 **REST Client 的 `.http` 文件**：把请求写成文件、点一下就能发，请求还能积累下来反复重放——它将陪你走完二十次课。

> 工具要求（二选一）：IntelliJ IDEA **Ultimate**（自带 HTTP Client）或 VS Code 装 **REST Client** 插件。Community 版 IDEA 没有内置 HTTP Client，请选 VS Code 方案。

在项目根目录创建 `requests.http`：

```
### 第1课 · 开业检查：店开了没有？
GET http://localhost:8080/hello
```

格式说明（就三条规矩）：

- `###` 开头是请求的标题，也是分隔符——一个文件可以放很多个请求
- 下一行是 `方法 + 完整 URL`
- 请求之间空行隔开

使用：启动程序后，点击请求上方的运行按钮（IDEA 是行号旁的 ▶，VS Code 是 "Send Request"），右侧/上方会弹出响应面板。

## 二、验证清单（全过才算下课）

**1. 开业检查**

发送上面那个请求，预期响应：

- 状态码：`200`
- 响应体（Response Body）：`南坡小炒，本店开业！`
- 展开响应头（Response Headers），找到 `Content-Type: text/plain;charset=UTF-8`——这就是第 1 课思考题的答案线索：响应头里写明了"这是什么类型的数据"。

**2. 故意看看 404 长什么样**

在 `requests.http` 里**追加**一个请求（同一个文件往下写就行）：

```
### 第1课 · 访问不存在的路径（预期 404）
GET http://localhost:8080/nobody-home
```

发送，预期：

- 状态码：`404`
- 响应体是一段 JSON：

```json
{"timestamp":"2026-09-06T...","status":404,"error":"Not Found","path":"/nobody-home"}
```

404 = "你访问的路由不存在"。**记住这段 JSON 的样子**——第 6 课的统一异常处理会接管所有错误响应，把这类"机器味"报错换成全店统一的信封格式。

验证全部通过后，在终端 `Ctrl + C` 停掉程序。

## 四、课后练习（不强制，但强烈建议）

1. **换个铺面**：把端口改成 8081，重启，把 `requests.http` 里的 URL 改成 8081 再发送成功。
2. **改店名**：新写一个 `@GetMapping("/goodbye")` 接口，返回"南坡小炒，今日售罄"，并在 `requests.http` 里加一个对应请求。
3. **思考题**（下节课开头提问）：为什么浏览器显示的是文字而不是乱码？提示：再看看刚才那个 `Content-Type` 响应头。
