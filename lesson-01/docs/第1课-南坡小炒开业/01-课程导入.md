# 第1课 · 课程导入：把店面立起来

## 你的故事开始了

你是成都理工大学工程技术学院的学生，也是南坡的常客——下课铃一响就往那儿冲。今天起，角色互换：**你要在南坡开一家自己的小炒店**，店名「南坡小炒」。

开店第一步不是学炒菜，是把店面立起来。这节课结束时，任何人打开浏览器访问 `http://localhost:8080/hello`，都能看到一行字：

```
南坡小炒，本店开业！
```

别小看这行字——它背后已经站着一个完整的 Web 服务器：你写的程序在监听 8080 端口，接收浏览器发来的 HTTP 请求，再把文字回应出去。这就是这门课要玩的东西：**用 Spring Boot 写"能被别人访问的程序"**。

## 本课你将学会

1. 用 Maven 组织一个 Spring Boot 4 项目（看懂 pom.xml 的每一块）
2. `@SpringBootApplication` 启动类是干什么的
3. 写第一个接口：`@RestController` + `@GetMapping`
4. 启动项目、看懂启动日志、用 requests.http（REST Client）访问接口
5. 建立 git 仓库，用提交记录你的开店史

## 课前检查

- [ ] JDK 17+ 已安装：`java -version` 能看到版本号
- [ ] IntelliJ IDEA **Ultimate**（自带 HTTP Client）或 VS Code + **REST Client** 插件——接口验证全靠 `.http` 文件
- [ ] 浏览器能访问 https://start.spring.io（项目骨架从它生成）
- [ ] 想好你的工作目录（比如 `~/temp/`），项目将解压在这里

## 一个先想清楚的问题：为什么是 Spring Boot？

用纯 Java 也能写网络程序，但你要自己处理：开端口、解析 HTTP 报文、管理线程、转 JSON……等你写完，饭馆都倒闭了。

Spring Boot 的思路是：**这些事所有人都得做，那我就替你做好，你只写业务**。这个思路叫"约定优于配置"——它定好规矩（比如网页文件放 `static/` 目录、端口默认 8080），你按规矩来，就不用写配置。

它给你准备好的一切，都打包成一个个"starter"（起步依赖）。你要开 Web 店，就引入 `spring-boot-starter-webmvc`，一个依赖自动拖来：内嵌 Tomcat 服务器、Spring MVC 框架、JSON 转换器。这就是"半成品套装"。

> **提醒**：老教程里这个依赖叫 `spring-boot-starter-web`。Spring Boot 4 把它改名成了 `spring-boot-starter-webmvc`。你课后搜资料看到旧名字，不是别人写错，是版本差异——这门课统一用 Boot 4.1.1。
