# 第18课 · 验证、提交与练习

## 一、requests.http 追加

```
### 18.1 说句话让小智下单（需登录 + Key；未登录 40101；无 Key 50002）
POST http://localhost:8080/order/ai
Content-Type: application/json
Authorization: Bearer <accessToken>

{ "message": "来份回锅肉，两碗米饭，再来个不辣的素菜" }

### 18.2 AI 识别不出菜品（预期 code=40401——幻觉被业务校验兜住）
POST http://localhost:8080/order/ai
Content-Type: application/json
Authorization: Bearer <accessToken>

{ "message": "来份北京烤鸭，要全聚德的" }
```

## 二、验证清单

**1. 权限验证（无 Key 也能测）**

- 不带令牌直接发 18.1 → `{"code":40101,...,"msg":"请先登录（缺少令牌）"}`——**AI 入口被第 16 课的查票员罩住了**，路径设计的胜利。
- 登录拿 accessToken 再发 → 无 Key 时 `{"code":50002,...}`（管线通到模型这一步才断）。

**2. 有 Key 的完整体验（本课高潮）**

带 Key 重启，登录后发送 18.1——预期返回**一张真订单**：

```json
{"code":200,"data":{"itemList":[{"dishName":"回锅肉",...},{"dishName":"米饭","count":2,...},
 {"dishName":"番茄炒蛋",...}],"msg":"下单成功，请到取餐口稍等～（订单号 N）","orderId":N,...},"msg":"操作成功"}
```

（"不辣的素菜"具体解析成番茄炒蛋还是别的，看模型发挥——**这正是自然语言点单的魅力**。）然后链式验证它"真"在哪：

- 重发 **16.7 翻账本** → 新订单赫然在列，`username` 是**你的登录名**（第 16 课的订单记名对 AI 入口同样生效！）
- 服务端日志：菜单查询 SQL + 落库 insert 三连 + `[墩子]→[厨师]` 照常开火——**和人工下单的日志一模一样**，因为走的就是同一条路。

**3. 幻觉防线**

发送 18.2（点全聚德烤鸭）→ `{"code":40401,...,"msg":"该菜品不存在"}`——模型就算真解析出了"北京烤鸭"，第 8 课的 `findByDishName` 也不认。**AI 负责翻译，账由老规矩管。**

**4. 工具调用体验**

发送 17.1 问"有什么菜"——回复里的菜名价格应与 2.1 查询完全一致（小智先调了 getMenu 工具）。服务端日志能看到工具触发的菜单查询 SQL。

**5. 浏览器**：登录后在 AI 区输入"来份回锅肉"，点红色"帮我下单"——✅ + 订单 JSON 直接出现在页面上。

## 四、课后练习

1. **提示词工程师初体验**：顾客说"随便来两个荤菜配三碗米饭"——试试现在的解析器行不行；不行就在 orderParser 的人设里补规则（比如"顾客说'随便'时你替他选菜单上最贵的两道荤菜"），直到满意。**改提示词不改代码**——这就是提示词工程的日常。
2. **给小智加一个工具**：仿照 MenuTool 写一个 `OrderTool.queryMyOrders(int userId)`（`@Tool` + 第 12 课的 `getOrderPage`），让小智能回答"1 号用户最近的订单"。
3. **思考题**：AI 下单走的是你的登录态（记你的名）。如果某天要支持"未登录游客语音点单"，架构上应该怎么记录下单人？（提示：第 20 课会有一种答案——系统身份 ai-guest。）

## 五、下一课预告

功能全齐了：点餐、会员、照片、AI。但它还"住"在你这台机器上——JDK 17、H2、本地磁盘，换个环境就未必跑得起来。"在我电脑上是好的"是工程师最著名的遗言。

下一课，连锁开店：**Docker 多阶段构建**把应用打成镜像，**docker-compose** 一条命令拉起 app + MySQL + MinIO 三个容器。两条埋了很久的暗线同时兑现——H2 换 MySQL、本地磁盘换 MinIO，**全部只靠环境变量和第 13 课埋的 StorageService 接口，业务代码一行不改**。你还会踩到两个教科书级的真实坑（数据库列宽、容器网络拓扑），踩完对"部署"的理解上一个台阶。
