# 第15课 · 动手做：用户表 + BCrypt + JWT 签发

共 8 步。新增文件较多，但每一步都很小。

## Step 1：pom 加四件套（10 分钟）

`pom.xml` 的 `<dependencies>` 里追加：

```xml
<!-- 第15课：JWT 三件套 -->
<dependency>
    <groupId>io.jsonwebtoken</groupId>
    <artifactId>jjwt-api</artifactId>
    <version>0.12.6</version>
</dependency>
<dependency>
    <groupId>io.jsonwebtoken</groupId>
    <artifactId>jjwt-impl</artifactId>
    <version>0.12.6</version>
    <scope>runtime</scope>
</dependency>
<dependency>
    <groupId>io.jsonwebtoken</groupId>
    <artifactId>jjwt-jackson</artifactId>
    <version>0.12.6</version>
    <scope>runtime</scope>
</dependency>
<!-- 第15课：只借 BCryptPasswordEncoder 这一个工具类，
     不引 spring-boot-starter-security 全家桶（Spring Security 是生产级方案，
     本课程先手写理解原理，知道它的存在即可） -->
<dependency>
    <groupId>org.springframework.security</groupId>
    <artifactId>spring-security-crypto</artifactId>
</dependency>
```

两处门道：

- **jjwt 拆三个包**：api（你 import 的接口，编译期用）+ impl/jackson（实现，`runtime` 只运行时需要）。业界惯例：依赖分"编译需要"和"运行需要"，能 runtime 就 runtime，少污染编译期。
- **spring-security-crypto**：注意不是 `starter-security`！全套 Security 会接管你所有的路由和过滤器（第 16 课结尾会再提它）——我们只想要里面那一个 `BCryptPasswordEncoder` 工具类。

## Step 2：User 实体（10 分钟）

新建 `entity/User.java`：

```java
package com.cdutetc.nanpo.entity;

import java.time.LocalDateTime;

import jakarta.persistence.Column;
import jakarta.persistence.Entity;
import jakarta.persistence.GeneratedValue;
import jakarta.persistence.GenerationType;
import jakarta.persistence.Id;
import jakarta.persistence.Table;

import lombok.Data;
import lombok.NoArgsConstructor;

/**
 * 会员实体（第15课）：谁在我店里有卡。
 * 注意：password 字段绝不放进任何 VO——第10课"实体不能外泄"的伏笔在这里兑现，
 * 将来谁把 User 实体直接序列化出去，密码哈希就裸奔了。
 */
@Entity
@Table(name = "t_user")
@Data
@NoArgsConstructor
public class User {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false, unique = true)
    private String username;

    /** BCrypt 哈希（$2a$10$... 共60位）——绝不存明文；同一密码每次加密结果都不同（自带随机盐） */
    @Column(nullable = false)
    private String password;

    private String nickname;

    private LocalDateTime createTime;
}
```

看点：`username` 加了 **`unique = true`**（唯一约束）——数据库层兜底，两个"小明"想都别想。`password` 字段的注释就是第 10 课"字段泄露"伏笔的兑现宣言。

## Step 5：JwtUtil——签发与解析（20 分钟，本课核心）

`application.yml` 的 `nanpo:` 段里（storage 之后）加：

```yaml
  # 第15课：JWT 密钥与有效期。密钥 ≥32 字节（HS256 要求）；
  # 生产环境用环境变量 NANPO_JWT_SECRET 注入，绝不把真密钥提交进仓库
  jwt:
    secret: ${NANPO_JWT_SECRET:nanpo-dev-secret-change-me-please-0123456789}
    ttl-minutes: 120
```

`${NANPO_JWT_SECRET:默认值}` 的读法："先找环境变量 NANPO_JWT_SECRET，找不到就用冒号后的默认值"——本地开发用默认值，**生产环境只注入环境变量、真密钥永不进仓库**（git 历史里删不掉的东西，提交前就要想清楚）。这套写法第 19 课部署时还会大放异彩。

新建 `common/JwtUtil.java`：

```java
package com.cdutetc.nanpo.common;

import java.nio.charset.StandardCharsets;
import java.time.Duration;
import java.time.Instant;
import java.util.Date;

import javax.crypto.SecretKey;

import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Component;

import io.jsonwebtoken.Claims;
import io.jsonwebtoken.Jwts;
import io.jsonwebtoken.security.Keys;

/**
 * JWT 工具（第15课）。
 * 令牌长这样：xxxxx.yyyyy.zzzzz 三段式——
 *   x=Header(算法)  y=Payload(数据+过期时间)  z=Signature(签名，防篡改)
 * 前两段只是 Base64（谁都能解开看，所以别放密码！），第三段用密钥签名——
 * 改一个字母签名就对不上。可到 jwt.io 现场解码体验。
 */
@Component
public class JwtUtil {

    @Value("${nanpo.jwt.secret}")
    private String secret;

    @Value("${nanpo.jwt.ttl-minutes:120}")
    private long ttlMinutes;

    private SecretKey key() {
        // HS256 要求密钥 ≥ 32 字节
        return Keys.hmacShaKeyFor(secret.getBytes(StandardCharsets.UTF_8));
    }

    /** 签发令牌：把"谁"（userId/username）和"有效期"写进 Payload 并签名 */
    public String generateToken(Long userId, String username) {
        return Jwts.builder()
                .subject(String.valueOf(userId))          // sub：主题=用户id
                .claim("username", username)               // 自定义声明
                .issuedAt(new Date())                      // iat：签发时间
                .expiration(Date.from(Instant.now().plus(Duration.ofMinutes(ttlMinutes))))  // exp：过期时间
                .signWith(key())                           // 签名
                .compact();
    }

    /**
     * 解析并校验令牌：签名不对/过期/格式坏都会抛 JwtException 子类。
     * 校验通过返回 Payload（Claims）。
     */
    public Claims parseClaims(String token) {
        return Jwts.parser()
                .verifyWith(key())
                .build()
                .parseSignedClaims(token)
                .getPayload();
    }

    public long getTtlMinutes() {
        return ttlMinutes;
    }
}
```

对照课程导入的三段结构读 `generateToken`：`subject`/`claim`/`issuedAt`/`expiration` 都是在往 **Payload** 里放键值对，`signWith` 生成第三段签名。`parseClaims` 则是反向：**先验签名和有效期（不对就抛异常），通过才把 Payload 给你**——"查票"的底层就是它，下一课的拦截器直接调用。

## Step 6：UserService——注册与登录（20 分钟）

新建 `service/UserService.java`：

```java
package com.cdutetc.nanpo.service;

import java.time.LocalDateTime;

import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder;
import org.springframework.stereotype.Service;

import com.cdutetc.nanpo.common.BusinessException;
import com.cdutetc.nanpo.common.ErrorCodeEnum;
import com.cdutetc.nanpo.common.JwtUtil;
import com.cdutetc.nanpo.dao.UserRepository;
import com.cdutetc.nanpo.dto.LoginRequest;
import com.cdutetc.nanpo.dto.RegisterRequest;
import com.cdutetc.nanpo.entity.User;
import com.cdutetc.nanpo.vo.LoginVO;

/**
 * 会员服务（第15课）：办卡（注册）与验证身份（登录发 JWT）。
 */
@Service
public class UserService {

    private final UserRepository userRepository;
    private final JwtUtil jwtUtil;

    // 只借 BCrypt 工具类，不引 Spring Security 全家桶
    private final BCryptPasswordEncoder passwordEncoder = new BCryptPasswordEncoder();

    public UserService(UserRepository userRepository, JwtUtil jwtUtil) {
        this.userRepository = userRepository;
        this.jwtUtil = jwtUtil;
    }

    /** 办卡：用户名查重 + 密码加密入库 */
    public void register(RegisterRequest req) {
        if (userRepository.findByUsername(req.getUsername()).isPresent()) {
            throw new BusinessException(ErrorCodeEnum.USERNAME_TAKEN);
        }
        User user = new User();
        user.setUsername(req.getUsername());
        // BCrypt：自带随机盐——同一个密码每次加密结果都不同，
        // 数据库被拖走也倒推不出原密码
        user.setPassword(passwordEncoder.encode(req.getPassword()));
        user.setNickname(req.getNickname() == null || req.getNickname().isBlank()
                ? req.getUsername() : req.getNickname());
        user.setCreateTime(LocalDateTime.now());
        userRepository.save(user);
    }

    /** 登录：验证通过就发 JWT 会员卡 */
    public LoginVO login(LoginRequest req) {
        User user = userRepository.findByUsername(req.getUsername())
                .orElseThrow(() -> new BusinessException(ErrorCodeEnum.LOGIN_FAILED));
        // 注意：用户不存在和密码错误统一报"用户名或密码错误"——
        // 不帮攻击者缩小爆破范围
        if (!passwordEncoder.matches(req.getPassword(), user.getPassword())) {
            throw new BusinessException(ErrorCodeEnum.LOGIN_FAILED);
        }

        LoginVO vo = new LoginVO();
        vo.setToken(jwtUtil.generateToken(user.getId(), user.getUsername()));
        vo.setExpiresIn(jwtUtil.getTtlMinutes());
        vo.setNickname(user.getNickname());
        return vo;
    }
}
```

三个安全细节，值得抄进笔记：

- **`encode` 存、`matches` 比**：登录不是"解密密码比对"，而是让 BCrypt 拿明文重算一遍和库里的哈希比对。
- **统一错误话术**：用户不存在（`orElseThrow`）和密码错误（`matches` 为 false）都报 `LOGIN_FAILED(40408)`——如果分开提示"用户名不存在"/"密码不对"，攻击者就能先枚举出哪些用户名存在，再集中爆破密码。
- **BCryptPasswordEncoder 是 new 出来的**：它是个无状态工具类，不像 Service 需要容器管理——判断"要不要交给 Spring"的依据是**有没有需要容器注入/管理的状态**，而不是"是不是框架里的类"。

## Step 7：UserController——会员窗口（10 分钟）

新建 `controller/UserController.java`：

```java
package com.cdutetc.nanpo.controller;

import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RestController;

import com.cdutetc.nanpo.common.Result;
import com.cdutetc.nanpo.dto.LoginRequest;
import com.cdutetc.nanpo.dto.RegisterRequest;
import com.cdutetc.nanpo.service.UserService;
import com.cdutetc.nanpo.vo.LoginVO;

/**
 * 会员窗口（第15课）：办卡与登录。
 * 第三个 Controller——店里新开了会员窗口。
 */
@RestController
public class UserController {

    @Autowired
    private UserService userService;

    // 办会员卡
    @PostMapping("/register")
    public Result<Void> register(@RequestBody RegisterRequest req) {
        userService.register(req);
        return Result.success();
    }

    // 登录：验证通过发 JWT 令牌
    @PostMapping("/login")
    public Result<LoginVO> login(@RequestBody LoginRequest req) {
        return Result.success(userService.login(req));
    }
}
```

> **常见报错**
>
> | 现象 | 原因 | 解法 |
> |---|---|---|
> | 启动报 `WeakKeyException` | 密钥不足 32 字节（自己改短了？） | 恢复默认密钥或凑足长度 |
> | 登录永远 40408 | 注册时密码没 encode（存了明文）？matches 自然不匹配 | 检查 register 是否走 encode |
> | `BCryptPasswordEncoder 找不到` | 依赖引成了 starter-security 之外漏了 crypto | 对照 Step 1 |
